# Maintaining the Skill

## Source files

Edit `skills/zero-slop/SKILL.md` for shared workflow guidance. Add detailed scenarios to `skills/zero-slop/references/interface-examples.md` and keep the scenario index and count in sync. Keep the visual atlas at `skills/zero-slop/assets/interface-examples.png`.

## Language and interface rules

Keep all repository documentation and skill materials in English. Product interface copy follows the product's language and locale. Avoid em dash and en dash punctuation in rendered interface text. Avoid the named common AI-default font families unless product evidence supports their use.

## Review checklist

- Keep examples concrete, contextual, and concise.
- Distinguish verified usability defects from personal taste.
- Preserve product behavior and limit changes to the requested scope.
- Confirm relative links and the visual asset still resolve.
- Run `npm run validate`.
