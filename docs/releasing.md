# Releasing

The repository starts at version 1.0.0 and is not published as an npm package. Update `CHANGELOG.md` when preparing a repository release.

The `.changeset/` directory is reserved for a future package release workflow. Do not add publishing credentials or automate publication without an explicit release decision from the repository owner.

The repository is currently marked `UNLICENSED`. Confirm the owner's desired license before making a public release.
