# Out of Scope

These items are not implied by using this skill:

- Redesigning unrelated routes or product areas.
- Replacing a working product flow with a mock.
- Changing product language, branding, or typefaces without product evidence or user direction.
- Deploying, publishing, or changing live data.
- Treating every scenario in the reference library as a mandatory feature.

The skill may address an item when the user explicitly requests it and the project context supports the change.
